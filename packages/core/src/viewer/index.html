READING THE RESULTS

Evidence, with limits.

Frame transactions separate validation, payment and execution. Admission is not proof that execution succeeded: inspect the recorded receipt and each frame status.

PASS covers the declared scenario in its recorded environment. FAIL identifies a failed check; it does not automatically establish an exploit. BLOCKED and INCONCLUSIVE require more evidence.

Aftershock tests the pinned sidecar implementation. Draft alternative-mempool rules and other client versions may differ. Read the source pins and preconditions with each report.

Replay currently creates fresh accounts and genesis. It compares action verdicts and stable environment fields, without restoring historical private state. Commands are displayed for manual use only.
